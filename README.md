# Overview

The Requirements.md file contains the problem statement, goals, non-goals, assumptions, solution approach and user stories.

The Design.md file contains the architecture, components, data models and APIs.

The Implementation.md file contains the implementation details, test infrastructure and artifacts.

The FAQ.md file contains various design decisions represented in an easy to understand FAQ format.

The ClaudeDirections.md file contains instructions for Claude Code to help with development.
